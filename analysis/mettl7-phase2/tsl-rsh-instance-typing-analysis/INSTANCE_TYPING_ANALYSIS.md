# TSL-RSH instance-specific torsion-typing analysis

Chemical classes were frozen from connectivity, bond order, substitution, sulfur/carbonyl adjacency, and graph symmetry before residual evidence was overlaid. No fitting or scientific calculation was run.

## Decision

Three C1 parents are chemically heterogeneous: `LOCAL_TYPE_2`, `LOCAL_TYPE_12`, and `LOCAL_TYPE_17`. The minimum residual-blind decomposition contains 13 total classes (7 additional classes relative to C1) while preserving five hard H9/H10 symmetry groups.

Instance-specific typing is chemically justified, but it is unlikely to be sufficient by itself: low-energy PHI/PSI cross-response remains large. A pilot on the existing 56 labels is scientifically testable before new QM; a thermally restricted PHI×PSI surface is likely required afterward if coupling remains.

Individual 1-4 pair trajectories are diagnostic only. Charges, SCEE, and electrostatics were not changed.
