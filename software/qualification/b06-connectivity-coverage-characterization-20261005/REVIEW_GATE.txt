WHY EXPLICIT IS INSUFFICIENT
Gaia Structure describes EXPLICIT as fully-mapped explicit connectivity. It does not
assert exhaustive bond assessment. Hermes PdbReader.importPdbConect marks EXPLICIT
when records map successfully (and earlier import was not partial); it does not prove
all covalent connections were supplied. importConnectivity likewise distinguishes
mapping success from unmapped source edges. ConnectivityMetadata has provenance and
diagnostics, not an independent completeness field. This is source-code inspection,
not a new PDB import experiment or claim that a particular real artifact is affected.
Existing group-source-coverage/1 does have state-bound component completeGraph coverage.
