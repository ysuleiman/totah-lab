6. ARITHMETIC, GEOMETRY AND ASSESSMENT
Parse exact pinned decimal target/esd using Java21 Double.parseDouble.
Let x be existing Athena DISTANCE/ANGLE output without rounding/recomputation.
Compute delta=x-target, then residual=delta/esd as two binary64 operations.
No FMA, reassociation, decimal quantization, epsilon, clipping or thresholds.
Retain x/delta/residual bits separately. esd must be finite and strictly positive;
invalid reference esd is a reference error/UNKNOWN, never infinite residual or pass.
Any nonfinite arithmetic result => UNKNOWN for that derived quantity; retain defined
raw measurements independently. Never serialize NaN/Infinity. Signed zero retained.
The term 'restraintNormalizedResidual' is descriptive, not a population z-score.
Zero, huge positive and huge negative finite values are all evaluated measurements.

Use existing geometry's degeneracy behavior unchanged. No new zero-length tolerance
or distance clamp. No cctbx coordinate-arithmetic parity claim. Independent scalar
oracles take exactly Athena-measured binary64 x; geometric qualification remains
Athena's existing primitive and its exact manifest/version is pinned.

Assessment priority: missing/invalid current authority or insufficient operational
budget => NOT_EVALUATED; with authority, any required unresolved/conflicting source
or applicability fact => UNKNOWN; otherwise known outside-domain facts => UNSUPPORTED;
otherwise reference missing/corrupt or required geometry unavailable => UNKNOWN;
otherwise successfully evaluated row => SUPPORTED_PRESENT. All intermediate statuses
remain visible even when final priority is NOT_EVALUATED. Malformed payload/binding
is rejected using existing error behavior, not converted to a scientific status.
Selection-level assessment is SUPPORTED_PRESENT only when all required rows evaluate;
one unknown geometry row gives selection UNKNOWN while other eligible row residuals
remain defined. ABSENT_FALSE is never used. No numerical value means normal, favorable,
energetically strained, erroneous biological function, or a request to repair coordinates.

Unchanged RuleRequest: first=[centralResidue], second=[], atoms=sorted distinct union
of all currently mapped required central heavy-atom coordinates for that exact STV
selection. Do not add neighbor/H atoms merely for authority or measure their geometry.
If source identity is unresolved, use the nonnull mapped central roles from A only;
no manufactured correspondence. State/manifest pins must match exactly. Existing
radius/hop limits are operational only, not chemistry. maximumNodes must cover the
selected mapped atom union and maximumCandidates must cover all10/13 expected rows;
insufficient budget => NOT_EVALUATED, no misleading subset/negative claim. Raw x may
remain; no residuals are reported from an incomplete-budget run.
