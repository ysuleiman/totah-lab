JUSTIFIED CHANGES
New v2 harness/metadata reuse the frozen v1 compiler, cache corruption checks,
JUnit identity/skip/failure checking and source rehashing. No v1 files changed.
The new checkpoint-specific isolation closure covers the exact compiled source
and test/resource dependency files. Each expensive class runs in its own JVM,
java.io.tmpdir and JUnit TempDir; test methods remain sequential. Reviewed helper
code reads pinned repository fixtures and writes only beneath its test tempdir.
No ports, database, common output path or shared mutable process state is used.
Any closure hash mismatch disables concurrency; per-class source pins are checked.
Unreviewed classes still execute serially before isolated jobs.

Selection fixes the direction of helper dependency propagation. A test merely
included for dependency regression is not a changed helper. Reverse helper
consumers are expanded only from actually changed test/helper files, transitively.
For example selecting unchanged B01 tests no longer drags every test importing
B01 fixture methods into a G06-only change. Editing a helper still includes its
transitive consumers. Unmapped changes or unknown test consumers escalate broadly.

There is one exact, hash-bound, already-qualified G06 change package for the
original seven source/test/resource changes, including the WaterIdentity delegate
and additive dispatch branches. The entire change-set and resulting bytes must
match. Partial/different shared changes cannot use that exception. Future generic
geometry, graph, matcher, Research Gate, source scope or dispatch changes continue
to require broad qualification. An automatic Tier3 escalation is reported and
stops execution unless Tier3 is explicitly requested; it never silently runs a
smaller set or launches an unwanted full release.

No class removal was necessary to meet the 3–5 minute target. G05 current-pipeline
coverage and old geometry/group suites are conservative retained coverage; their
removal would save less wall time under isolated concurrency and need additional
justification. This avoids trading scientific protection for nominal test count.
