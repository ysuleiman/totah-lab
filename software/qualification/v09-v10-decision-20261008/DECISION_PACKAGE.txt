2. MATERIAL SOURCE DIFFERENCES — DO NOT MERGE
A. Current Rama code reads compiled doubles generated with six significant decimal
 digits. Full-precision raw-text evaluation and deprecated NDimTable float storage
 are different numerical contracts. Audit reconstructed all 194400 compiled cells
 from the six original text files using the upstream recipe: ZERO mismatches.
 Full raw precision differs at 110671 listed cells; see GRID_AUDIT.json for exact
 per-table counts and maximum differences. No empirical table was invented.
 Recommended authority: exact pinned compiled table + current C++ interpolation;
 retain raw text and generation recipe as attributed provenance.

B. Rotamer README says the 0.3% outlier boundary is inclusive. rotalyze.evaluateScore
 and RotamerEval use score >=0.003 as Allowed, with score <0.003 as OUTLIER.
 Recommended: cctbx category profile, exact 0.003 is Allowed. This is explicitly
 not literal README boundary parity. Choosing <=0.003 OUTLIER would require a
 separately named, separately tested README-derived profile.

C. Rama is_cislike_peptide uses -90 < omega <90 degrees; a deprecated cis helper
 uses -30 <omega<30. Select the former for cis-PRO table assignment only. This
 is not a universal cis-peptide quality/strain classification. Exactly +/-90
 uses trans-PRO. Upstream missing omega falls through as trans; Athena proposal
 refuses that inference and reports UNKNOWN when PRO table selection is unresolved.

D. Upstream wrappers can map MSE/modified parents or derive chain neighbors and
 conformers. None is imported as source authority. Athena requires explicit source
 correspondence, peptide connections and coherent alternative identity. No atom-name
 label alone, residue-number adjacency, distance cutoff, highest-occupancy assembly,
 inferred bond or automatic parent/tautomer normalization establishes admission.

E. Current Rama string lookup searches only the first five strings and returns
 index5 on failure, conflating unrecognized strings with Ile/Val. The first profile
 has a closed reviewed enum 0..5 and rejects unknown class tokens. Do not reproduce
 a permissive unknown-string path as chemical eligibility.

3. V09 EXACT BOUNDED DOMAIN / CLASS ASSIGNMENT
One explicitly selected internal canonical alpha-peptide residue in an explicitly
connected, coherent protein triplet, with independently qualified source residue
identities. Central source identity must be one of:
 ALA ARG ASN ASP CYS GLN GLU GLY HIS ILE LEU LYS MET PHE PRO SER THR TRP TYR VAL.
Require ordinary L stereochemistry for chiral canonical residues, ordinary native
side-chain identity (including the native ILE/THR stereochemistry), or achiral GLY.
No D-residue mirroring, unknown chirality, noncanonical backbone, beta residue,
N-methyl substitution or label-only mapping. Source charge/H/protonation/isotope
facts are retained without normalization; no new protonation/role classifier is
implied. Modified side chains, unreviewed parent mappings, cyclic peptide contexts
and known nonordinary source attachments are outside this first admission profile.
Unresolved identity/connection coverage is UNKNOWN, not proof of exclusion.

The complete source-admission producer/protocol and exact allowed side-chain state
inventory must be pinned and reviewed before a coordinate-consuming implementation
can be activated (section8). This package defines the numerical/domain target; it
does not claim those identity facts are already independently qualified in Athena.
If that inventory is not ready, keep source admission blocked rather than reducing
identity to a residue label. An explicitly reviewed selected-source assertion can
be proposed for approval; a caller's class enum cannot self-qualify its chemistry.

Exact ordered torsions:
 phi_i = (C_{i-1}, N_i, CA_i, C_i)
 psi_i = (N_i, CA_i, C_i, N_{i+1})
 omega_in_i = (CA_{i-1}, C_{i-1}, N_i, CA_i), required for central PRO.
Require source bonds Cprev-N, N-CA, CA-C and C-Nnext; no bond-length surrogate.
Require exact current/next residue identities for class selection even if the
selected atoms already yield numerical phi/psi. No chain-wide aggregate initially.

Precedence from ramalyze.py:
 1 GLY -> glycine, including GLY followed by PRO.
 2 PRO -> cis-proline if -90<omega_in<90; otherwise trans-proline for defined omega.
 3 non-GLY/non-PRO followed by PRO -> pre-proline, including ILE/VAL before PRO.
 4 remaining ILE/VAL -> isoleucine-or-valine.
 5 remaining admitted residues -> general.
Missing required neighbors, unknown next identity or unresolved PRO omega => UNKNOWN.
A terminal residue lacking a required torsion does not become a geometric outlier.
No automatic chemical-completeness claim from coordinate records.

4. V09 NUMERICAL / CATEGORY CONTRACT
Every table is 180x180, axes [-180,180], periodic360, grid centers -179,-177,...,179.
Use phi as first/row index and psi as second/column, matching cctbx c_grid order.
For each finite angle bring into [-180,180] by the pinned 360-degree range logic;
retain original angle and ranged angle. +180 and -180 interpolate the same seam.
Use the current source algorithm exactly:
 lower=floor(angle); if lower is even, lower-=1;
 higher=ceil(angle); if higher is even, higher+=1;
 if lower==higher, higher+=2.
 bin=int((gridCoordinate+179)/2), wrapping <0 or >179 by180.
Grid coordinates at a seam extend to -181/+181 while lookup bins wrap.
For valid ordinary coordinate torsions the range is already bounded. Nonfinite or
unbounded caller-supplied angles are not admitted by this first coordinate profile.

Interpolate lower/lower -> higher/lower along phi and lower/higher -> higher/higher
along phi; then interpolate those two results along psi. Preserve upstream
linear formula y1+(y2-y1)*(x-x1)/(x2-x1), in this order. Use binary64 compiled values;
no alternate smoothing, nearest-bin shortcut, FMA substitution or classifier epsilon.
Native Athena geometry may only be reused once signed torsion order, wrap and
undefined-coordinate handling are demonstrated against pinned upstream fixtures.
No parity claim currently exists for that composition.

Raw score q is a dimensionless empirical contour rank/validation quantity, not an
energy or a posterior probability of a correct model. Display100*q is percentage;
classification uses q itself, not rounded/displayed percentage.
 All classes: q>=0.02 => FAVORED.
 General: 0.0005<=q<0.02 => ALLOWED; q<0.0005 => OUTLIER.
 Cis-PRO: 0.002<=q<0.02 => ALLOWED; q<0.002 => OUTLIER.
 Gly/trans-PRO/pre-PRO/Ile-Val: 0.001<=q<0.02 => ALLOWED;
                              q<0.001 => OUTLIER.
OUTLIER is a named reference-validation category, not binding failure, strain
energy, incorrect identity, biological insignificance or rejection authority.

5. V10 EXACT FIRST DOMAIN / NUMERICAL CONTRACT
Selected internal ordinary L-SER, L-THR or L-VAL residue in explicit peptide
connectivity; no inferred residue/atom naming, no source graph transformation.
SER: exact ordinary CH2-OH side chain; THR: native threonine CH(OH)-CH3 including
its source-established beta stereochemistry; VAL: CH(CH3)2 with source-established
atom correspondence. Exclude phospho-/glyco-/deprotonated hydroxyl states, allo-THR,
D residues, modified or unidentified source chemistry. Full source identity,
formal state and H-count facts must be independent of grid selection. H coordinates
are not required for these heavy-atom torsions and must not be synthesized.
Source-admission protocol still requires section8 review; no new chemistry role
catalog is authorized merely by selecting a grid.

Ordered chi1 from exact sidechain_angles.props:
 SER: N,CA,CB,OG
 THR: N,CA,CB,OG1
 VAL: N,CA,CB,CG1
VAL CG1/CG2 must retain exact authoritative stereospecific correspondence. Do not
swap labels to maximize a score or treat arbitrary isomorphic maps as equivalent.
No named m/p/t assignment, rotamer frequency, central-angle tolerance or pKa rule.

All three grids have360 bins, bounds0..360, centers0.5..359.5, width1degree, wrap=true.
Use upstream NDimTable storage: parse each text value, store as IEEE binary32
(flex.float), then promote stored values for binary64 arithmetic. Parsing text
straight into retained binary64 gives a different numerical profile.
Coordinate-derived chi is signed in [-180,180] with the pinned scitbx dihedral
convention. Use that signed value directly in the pinned valueAt path:
 home=min(floor(chi),359); center=home+0.5;
 neighbor=home-1 if chi<center, otherwise home+1;
 w=abs(chi-center); lookup home/neighbor using positive modulo360;
 value=(1-w)*float32_table[home mod360] + w*float32_table[neighbor mod360].
This has upstream sum order home contribution then neighbor contribution.
Negative indices wrap; the logical center is not first clipped to0. Exact360
may be used in seam characterization but arbitrary multi-turn inputs are excluded:
whereIs caps its upper bin, so calling the unmodified evaluator on chi>360 would
not be a general periodic-normalization contract. Do not claim arbitrary-angle
upstream parity. Positive-modulo display of chi is separate from scoring.

Recommended cctbx categories:
 q>=0.02 => FAVORED; 0.003<=q<0.02 => ALLOWED; q<0.003 => OUTLIER.
Keep raw score and signed measured angle, selected class/grid and category separate.
This is selected SER/THR/VAL chi1 validation, not full V10 rotamer coverage.

unknown parser version or unverified source package is ineligible/UNKNOWN; never

source state/model/frame, residue identity and connection witnesses, ordered atom
correspondence, original/measured/ranged torsions, interpolation bins/weights,

zero score under a complete selected table is an OUTLIER category, not missing data.
Only selected-residue coverage is asserted; no whole-protein absence/completeness.
No inferred altloc correlation, occupancy weighting, missing-atom inference,
chain repair, coordinate imputation, energetic interpretation or master score.

seam/bin/interpolation/storage, exact category nextUp/nextDown, ambiguous chemistry,

boundaries. No invented tolerance: exact category agreement mandatory; any numeric
