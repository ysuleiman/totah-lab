Scientific reviewer AGENT:athena.foundation.authority:project-user:1.

EXACT PROJECTION /2

schema, ruleId, version, profile, family, tier, requiredCapabilities, requiredChemistry,

limitations, negativeCoverage; include domainSha256 as before.

referenceArtifacts cannot hide scientific definition changes as mere implementation pins.

ACCEPTANCE
Human-only science; executor-only implementation/context; swapped/unauthorized roles fail.
Implementation-only version change: scientific digest unchanged; old report/receipt rejected;
new verified report may qualify against unchanged still-valid human review.
Changes to definition/domain/perception/measurement/threshold/coverage/scientific sources:
old scientific approval rejected. Full provenance/source tamper and expiry fail closed.
Per-rule different validity intervals; no universal default; expired evidence preserved.
NOT_APPLICABLE exact graph accepted with attribution; applicable unanalyzed dataset rejected.
No automatic review, renewal, receipt or imported fixture authority. Mixed versions fail.
Historical bytes/replay, current runCurrent/evaluateCurrent, invocation counts, admission,
explicit input selection, persistence/read-back and independent-JVM replay unchanged.
