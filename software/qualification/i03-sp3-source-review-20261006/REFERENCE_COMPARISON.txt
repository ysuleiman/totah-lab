OpenChemLib:
Pinned local JAR2026.7.2 with SHA256 in OCL_REFERENCE_PROTOCOL.json; upstream tag
2026.7.2 resolves to e18e34e33e56f8574d7224b7443ec54fada2378f. Downloaded tag and
immutable-commit ExtendedMolecule.java bytes were verified identical.
getAtomPi returns an atom pi-electron/bond-related count; it does NOT answer whether
an N lone pair participates in resonance. isFlatNitrogen is a different boolean
heuristic, with aromatic/pi, amide/enamine, ortho-substitution, three-membered-ring
and pyramidal-bridgehead logic. Neither pi=0 nor flat=false is an SP3 certificate.
No OpenChemLib flatness decision or steric/ring heuristic is imported into S1.

Observed distinctions, exact synthetic SMILES retained in REFERENCE_PANEL.tsv:
- Methyl/di-/trimethylamine: RDKit SP3; OCL pi0/flat=false.
- Acetamide: RDKit SP2; OCL pi0/flat=true. Thus zero OCL pi does not establish SP3.
- Sulfonamide CS(=O)(=O)[NH2:1]: RDKit SP3; OCL pi0/flat=true.
  These APIs describe different propositions. S1 excludes this context regardless.
- Hindered aniline Cc1cccc(C)c1[N:1](C)C: RDKit SP2; OCL flat=false.
  S1 excludes all direct aromatic attachments and does not adopt a steric rescue.
- Ynamine C#C[NH2:1]: RDKit SP2; OCL pi0/flat=false. S1 rejects the unsaturated
  adjacent-carbon environment without declaring a universal physical SP2 state.
- Enamine C=C[NH2:1]: RDKit SP2; OCL flat=true; S1 excludes direct carbon unsaturation.
- Methylammonium/quaternary ammonium, the represented aminyl radical, hydrazine
  and the represented zinc-dative example all have RDKit SP3 in this panel.
  They remain outside S1; SP3 labels do not imply approved I03 role eligibility.
- The aminyl example retains RDKit radicalElectrons1 and OCL radical token32.
  The dative example retains OCL metalNeighbors1. Those facts must not be dropped.
- Benzylamine, allylamine and the alpha-carbonyl spacer example differ from direct
  aromatic/alkenic/carbonyl N attachment; the saturated spacer is decisive for S1.
- Aziridine, pyrrolidine, piperidine and quinuclidine have RDKit SP3/OCL flat=false
  here. This is not proof that every N bond angle is109.5 or of pure orbital mixing.

Reference interpretation:
The same label or a superficially similar API must never substitute for the
reviewed Athena proposition. Agreement is useful for finding encoding mistakes;
disagreement requires preserving distinct definitions and examining source facts,
not majority voting or declaring a toolkit ground truth. No agreement percentage
is computed. The S1 decision rules are proposed scientific choices, not fitted to
these31 outputs. Positive/negative S1 cases still require a separately qualified
source-evidence protocol and independent implementation tests after approval.
