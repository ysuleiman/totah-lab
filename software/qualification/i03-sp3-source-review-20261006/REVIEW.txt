Why this can be bounded:
The five existing role manifests supply three exact neutral N constitutional
classes and retain occurrence-local acyl/amidino/sulfonyl exclusions. A complete
three-single-bond N pattern plus a neutral saturated four-single-bond environment
at EACH attached carbon gives a finite conservative admission rule without
searching general resonance forms or implementing toolkit-wide hybridization.
Explicit source electronic-state and connection coverage are additional independent
requirements. Four-coordinate carbon is a source count test, not a hidden carbon
hybridizer. Integer charge/H/bond predicates are explicit chemistry definitions;
no empirical cutoffs, pKa, fitted angle, radii or reference distributions are added.
The literal SP3 denotes this specified model. Actual hybrid orbitals are not
observable categorical labels supplied by this graph computation.

Material distinctions (not silently resolved by coding):
A. Strict saturated-attachment S1 vs a broader exclusion-list model.
S1 excludes direct unsaturated/aromatic/charged carbon attachments. A broader
three-sigma-N model with selected resonance exclusions would admit additional
contexts or require steric/ring exceptions. Those are different scientific
contracts. S1 is recommended; no broad resonance/steric engine is proposed.
B. Formal source-graph model vs geometry/orbital interpretation.
S1 uses no geometry and allows saturated rings/cages under the same source pattern.
An acyclic-only initial scope is a defensible narrower alternative. A geometry-
validated pyramidal-N model would require a separate contract, independently
attributed geometry and noninvented criteria. It is not selected here. No ring
size, planarity or pyramidalization threshold is smuggled into S1.
C. Explicit electronic-state/source coverage vs ordinary-valence defaulting.
Recommend whole-component existing V03 NONE evidence, never missing=>NONE. This
will leave many current records UNKNOWN. An explicitly adopted closed-shell
input-format convention could be reviewed separately but is NOT inferred from a
successful role match, sanitizer or external toolkit zero. The current reference
panel does not provide independently qualified source NONE evidence.
D. Excluded is not necessarily NOT-SP3.
Amides (including constrained/twisted), amidines' amino N, sulfonamides, aniline-like
attachments and charged N are excluded contexts, not universal assertions of SP2.
Only direct N multiple-bond/aromatic incompatibility receives a bounded NOT_SP3
model diagnostic. This remains distinct from unsupported and unresolved cases.
E. Scientific evidence semantics.
The carrier/Java APIs can be reused, but a new source-scope interpretation profile
is proposed because current completeGraph/EXPLICIT evidence does not establish
lossless coordination/electronic-state coverage. Its normative keys and semantics
are in EVIDENCE_PROPOSAL.txt and require approval before implementation.
