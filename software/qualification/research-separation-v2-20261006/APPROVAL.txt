## Invalidating-change semantics

Approved separation:

### Scientific invalidation

Includes changes to:

- definition
- domain
- perception semantics
- measurement semantics
- scientific references/distributions
- classification or thresholds
- negative coverage
- materially relevant scientific sources

These require new scientific review.

### Implementation invalidation

Includes changes to:

- implementation identity/version
- executable/source/artifact pins
- fixtures/tests
- execution binding
- context binding
- implementation qualification
- receipt binding

These require new implementation qualification/receipt but must not erase an unchanged, still-valid scientific review.
