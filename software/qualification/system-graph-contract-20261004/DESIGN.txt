1. Boundary and ownership
Implement only durable evidence integration, a read-only state-qualified system
view, and capability-specific startup certification. Stop after qualification.
No fragment growing, chemistry generation, docking, rescoring, energies, biological
mode selection, new METTL7 conclusion, generic inventory, DB/UI wiring, WELD,
Hephaestus consolidation or module restructuring. No new molecular representation.

Gaia: existing Structure/Atom/Residue/Bond and full ResidueGraph remain structure
and coordinate authority. Pocket is a derived computational view, not a filter on
which entities may influence or be recorded in analysis.
Current chemistry backend: MolecularGraph and chemical services keep ownership.
Athena: system-view correspondence, chemistry/geometry checks, scientific analyzer
contracts and capability/certificate interpretation. Existing graph-edit receipts,
interaction and clash records remain authoritative within their scoped methods.
Mnemosyne: immutable evidence envelopes, provenance, append-only interpretation
history, integrity/admission and persistence. No molecular classes or scientific
rules move into Mnemosyne.
Daedalus: orchestrates preserve/build/validate/analyze/certify/publish via existing
modules; publication is a returned/read-back qualified handle, not web/database work.

Gaia graph/ResidueGraph: original structure, residue nodes, sequence edges,

Athena interaction/InteractionProfiler: existing classified interactions with raw
measurements, thresholds, perception provenance and limitations.
Athena clash/StericClashAnalysis: existing clash results and explicit radii/scale.
Athena geometry and pocket/architecture: existing spatial measurements, not new
energy or mechanistic models. FragmentRegionFitCalculator remains unchanged unless

Mnemosyne extension points:
- ScientificReference.Kind: new envelope/interpretation kinds, not new molecular IDs.

- EvidenceExchange: version-3 record/snapshot support, extending the existing codec.
- EvidenceAdmission: unchanged append-only/integrity policy, including inherited
  envelope/interpretation digests; interpretation support is NOT an admission test.

- EvidenceLineage: reuse ancestry and corruption checks, no branch preference.
Do not add a second catalog, independent evidence inventory or competing journal.
The existing design journal may reference persisted evidence/certificate pins;

Existing daedalus.evidence.index.ScientificStateIndex remains the source-discovery

3. Proposed public additions / schema changes requiring review
Names are proposed concrete implementation targets, not existing classes:
mnemosyne.EvidenceEnvelope
  reference; open namespaced evidenceType and payloadFormat/version strings;
  exact opaque payload bytes (defensively copied, encoded without reinterpretation)
  or a verified durable artifact reference; source/artifact/receipt references;
  producing method/version; context; qualifications and limitations as supplied;
  ordered state-scoped subject references and collections; original payload digest.
mnemosyne.EvidenceInterpretation
  immutable versioned identity; referenced envelopes; evaluator/method version;
  exact configuration/evidence pins; subjects; assessment status; measurements;
  reasoning; limitations; optional explicit supersedes reference. Never overwrites.
mnemosyne.EvidenceSubject
  versioned state reference + open entity-kind string + source/local entity reference,
  or an immutable explicit member collection. Supports atom, residue, fragment,
  molecule, component, transformation, coordinate state, whole system and future
  kinds without importing domain classes. Unknown/unresolved kinds are preserved.

New exchange/record schema /3; old /1 and /2 accepted unchanged. Old records retain
original encodings/digests. Existing Observation, Assessment and their enum meanings
are NOT rewritten to approximate these new semantics. Extend History and branch
query constructors/accessors compatibly; enumerate any unavoidable breaking change
before coding rather than silently changing a public record constructor.
Unknown PAYLOAD types under the known envelope are durably readable and round-trip.
Unknown outer transport schemas and corrupt bytes are not falsely admitted as valid
records: retain source artifact and record decode/integrity limitations separately.
Large evidence remains in its verified durable authoritative artifact, with locator
and digest; do not duplicate large scientific datasets or impose chemistry parsing
as a prerequisite to preservation. A missing artifact cannot be claimed preserved.

athena.system.SystemStateView (proposed package)
  read-only composition of original full ResidueGraph, component MolecularGraph
  references, exact atom correspondence and explicit source/coordinate state pins.
  No new atom/bond storage representation. Missing correspondence is explicit.
  Neighborhood traversal returns existing relationships plus traversal coverage.
athena.system.SystemGraphCertificate
  immutable identity/digests, validation findings, per-capability qualifications,
  analyzer assessment references, preserved-evidence snapshot pin and limitations.
athena.system.SystemGraphAnalyzer
  versioned analyzer contract with required capabilities, exact configuration,
  subject/neighborhood selection and explicit output assessments.
daedalus.system.SystemQualificationPipeline
  orchestrates lifecycle, durable read-back, analyzer isolation and publication gate.
No new third-party dependencies. Existing module direction stays acyclic.

4. State identity / binding
Bind state to exact source system/components, chemical graph content, full coordinate
frame digest, atom ordering, correspondence digest and source artifacts. Reuse
AtomReference/ResidueId/MolecularGraph IDs; qualify them by system/coordinate state.
A bare residue number, component ID or canonical chemical identity is insufficient.
Preserve distinct coordinate/protonation states, symmetry alternatives and mapping
ambiguity. Do not silently choose a correspondence, infer missing bonds, reconstruct
hydrogens, recharge atoms or turn component ideal coordinates into pose coordinates.
Frame consistency requires source/frame provenance as well as numerical checks;
plausible coordinates alone cannot prove that independently sourced components align.

5. Preservation and lifecycle
Source/evidence preservation precedes evaluator execution and capability publication.
BUILD -> VALIDATE -> ANALYZE -> CERTIFY -> PUBLISH is the qualified-use lifecycle,
not permission to erase malformed, unsupported or failed source inputs.
Append and read back evidence before running analyzers. Failure appends FAILED and
keeps input evidence/state. Unknown type appends UNSUPPORTED, not a storage rejection.
Contradictions coexist, even between evaluator versions. No timestamp preference,
master score or automatic scientific resolution. New interpretation/certificate =
new immutable record, never mutation or replacement of the observation.

Assessment status values:
SUPPORTED_PRESENT, ABSENT_FALSE, NOT_EVALUATED, UNSUPPORTED,
UNKNOWN_INCONCLUSIVE, FAILED.
Presence of an evidence record remains separate from support for its proposition.
ABSENT_FALSE requires a completed applicable check with sufficient coverage; an empty
result caused by missing H/type information is not a negative chemical finding.

Capability status values:
QUALIFIED, CONDITIONAL, NOT_EVALUATED, UNSUPPORTED, FAILED.
Each capability includes required checks and reasons; no aggregate graph PASS/FAIL.
At minimum: distance queries, neighborhood traversal, graph transformations, clash
analysis, interaction typing and H-bond analysis. Energetics stays NOT_EVALUATED.
Missing chemistry can qualify distances while leaving chemical capabilities
conditional/unsupported. Failed coordinate/correspondence checks block dependent
capabilities, not unrelated evidence preservation.
Callers request capabilities and explicitly inspect conditions. Conditional is not
silently promoted to qualified. Verify certificate/state/config/evidence bindings
at use time; a stale certificate cannot authorize a changed state.

6. Validation / analysis
Chemical: topology, authoritative bond orders, available formal charges, stereo,
component identity, H/protonation availability, unresolved chemistry. Do not claim
that successful sanitization certifies a biological protonation state.
Geometry: finite coordinates, explicit covalent geometry under named criteria,
coincident atoms, clashes, spatial-index versus brute-force fixture agreement,
component frame provenance/consistency. Missing evaluable rules => NOT_EVALUATED
or UNSUPPORTED, not invented validation. No new covalent-geometry force field.
Correspondence: endpoint existence, declared mapping cardinality, completeness and
ambiguity; unmapped references remain evidence subjects with resolution status.

Traversal starts from any explicit atom/residue and can continue outward through
separately labelled chemical/spatial/interaction relationships. Distance cutoff,
atom selection, hop limit, visit budget and traversal completeness are recorded.
Cycles use visited identities; exhausted limits mean incomplete coverage, not
absence beyond the boundary. Pocket membership and ligand contacts never stop it.
No physical coupling or biological interaction inferred from a spatial path.

Initial analyzers: adapters around existing distance/clash/interaction services,
plus the validation checks above. The requested motif list is NOT authorization for
new scientific motif detectors. Hydrogen-bond networks, sulfur motifs, electrostatic
mechanisms etc. without existing qualified rules remain explicit unsupported requests.
For Cys/Cys demonstration: preserve actual sulfur-atom distance measurements and
subjects; report motif rule UNSUPPORTED if none exists, or INCONCLUSIVE if an existing
rule lacks necessary inputs. No invented disulfide threshold or bond assertion.

8. Required acceptance tests
P1 Unknown payload type survives durable write/read, exact bytes/digest and subjects.
P2 Contradictory observations/methods coexist across snapshots and journal references.
P3 NOT_EVALUATED differs from ABSENT_FALSE after serialization and queries.
P4 Evaluator exception retains durably committed evidence; appends FAILED.
P5 Later interpretation appends without changing original payload/hash or prior records.
G1 Valid synthetic state receives an immutable, read-back certificate.
G2 Partial chemistry qualifies distance capability and conditions H-bond capability.
G3 Second-shell traversal beyond direct ligand contact; arbitrary residue identities.
G4 Unsupported evidence survives certification and remains queryable by its reference.
G5 Analyzer failure leaves state/evidence intact and blocks only dependent capabilities.
G6 Contradictory motif assessments survive without ranking or overwrite.
G7 Ruleset upgrade produces distinct certificate; previous bytes/digest unchanged.
G8 Changed contact cutoff changes derived findings where appropriate, never evidence.
G9 Changed coordinate, chemistry, correspondence, config or input-evidence pin makes
   a previously bound certificate inapplicable to that changed state.
G10 Indexed versus brute-force distances; boundary inclusion, H selection, cycles,
    traversal budgets, incomplete coverage and out-of-pocket influence.
G11 Atom/residue/component/transformation/system and entity collections round-trip;
    unresolved/unknown subjects are preserved without false resolution.
G12 Existing exchange /1 /2 round-trip unchanged; append-only identity conflict and
    tamper detection; branch isolation; interrupted writes and durable read-back.
R1 Frozen fixture pins, exact pose identity, complete coordinate/frame preservation,
   explicit C202/C203 traversal and qualified/unsupported Cys/Cys motif handling.
No real-data numerical outcome is predeclared or used to select the fixture.
