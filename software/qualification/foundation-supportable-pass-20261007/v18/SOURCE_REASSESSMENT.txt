V18 — source semantics reassessment, 2026-10-07
Dependency: exact original format bytes/model/selection protocol -> lossless source
atom correspondence/presence evidence -> independently selected expected topology
for composition/missing-atom claims -> immutable state/coverage/Research Gate.
No missing atom can be deduced from proximity or source element inventory alone.

Concrete existing representation limits: Hermes PdbReader.buildAtom forwards the
BioJava primitive occupancy and temperature-factor values into Gaia Atom doubles.
Those doubles alone cannot distinguish blank original fields from a parsed numeric
zero. PdbReader.representativeAtoms selects each atom name independently by occupancy
and then altloc rank; AlternateLocationProvenance retains selected label and whether
alternatives existed, but not every omitted alternative's complete source fields.
That is existing representative-reader behavior, not a qualified joint conformer
selection protocol. Do not rewrite it or upgrade it to complete experimental-state
coverage. PDBQT's nullable source fields are a different format contract; its writer
can emit0.0 for absent values, so roundtrip bytes cannot recreate missingness.

A raw source audit can preserve field presence, selected atom inventory and declared
links, but that alone is not the remaining expected-composition/linkage/coexisting-
state scientific predicate. No expected component release/protonation/end-group/
residue/linkage protocol has been selected for this capability. The external CCD-
related data row remains separate; source names or element counts are not substitutes.
Any follow-on bounded profile must specify original format/version, explicit model
and alternate selection, original field-presence handling, exact expected component
state, link semantics, and source-to-state mapping before negative coverage.

Required matrix: blank versus zero occupancy/B; unknown value versus explicit source
zero; missing expected atom versus absent expectation; alternate atoms with mutually
incompatible selections; changed model/chain/insertion/serial; declared versus inferred
links; partial/conflicting source inventory; stale source/expected-model hashes;
independent current authority and deterministic original-byte replay. No empirical
occupancy/B-factor cutoff is proposed and no new parser/schema/production authority
is implemented. Existing source fields remain preserved, not silently reinterpreted.
