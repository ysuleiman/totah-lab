Dependency chain: unchanged P03 neutral CARBONYL_O identities and P09 source
coverage -> exact source correspondence and qualified same-state coordinates ->
existing FeatureTemplateAlignmentEvaluator/KabschRigidPointAligner -> independently
reviewed explicit query template and Research Gate. No new matcher, feature finder,
graph search, alignment algorithm, fingerprint engine or chemistry role.

Bounded question: does one explicitly selected ordered correspondence of exactly
three distinct neutral carbonyl-O feature occurrences satisfy an explicitly supplied
three-point template RMSD bound under the existing rigid least-squares alignment?
Each oxygen retains its exact mapped carbonyl carbon; all six source atoms distinct.
All three source occurrences must coexist in one complete immutable component/state.
The three template feature IDs are distinct and each requires the exact unchanged
CARBONYL_O role. User-provided correspondence selects the feature-to-template mapping;
no search, best-of-many selection, feature substitution or chemical equivalence
inference. This is selected 3D query satisfaction, not general 2D fingerprints,
whole-molecule pharmacophore search, full RDKit/PheSA compatibility or affinity.

Existing FeatureTemplateAlignmentEvaluator intersects feature names and can ignore
missing requested names. The wrapper must first require exact three-to-three coverage
and correct source roles before invoking it. Never accept a convenient partial fit.
Both point triplets require finite distinct noncollinear coordinates; exact zero
cross-product is degenerate, with no invented angular/planarity tolerance. Proper
rigid alignment and RMSD reuse the existing implementation. No chirality, orientation
of a lone pair, directional acceptor vector or inferred H geometry is claimed.

The threshold is a required attributed QUERY INPUT, not an Athena scientific default.
No fixed pharmacophore tolerance is selected or invented. Qualification uses clearly
synthetic query values only to verify mathematical behavior; no engineering example
becomes production scientific authority. Real execution must bind the exact query
bytes/source/protocol and maximumRmsdAngstrom into its independently reviewed current
scientific definition/manifest. A missing/unreviewed bound is NOT_EVALUATED, never
an invented default. Pass iff computed finite RMSD <= that exact supplied bound,
inclusive, without epsilon or rounding. Report RMSD and query bound separately.

Source comparison: RDKit feature definitions and OCL pharmacophore facilities supply
different feature perception/center/dialect meanings. This profile instead reuses
only Athena's already-qualified carbonyl atom roles. Existing Athena alignment is a
mathematical operation against a caller-configured maximum, not a universal chemical
window. P07 catalog weights, generic centroids and full toolkit feature catalogs are
not silently merged into these oxygen point features.
