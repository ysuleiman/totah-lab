DEPENDENCIES

identity; unchanged ATHENA.PERCEPTION.ACCEPTOR.CARBONYL_O; P09 source coverage;

DEFINITION / DOMAIN
An explicitly selected ordered tuple [Cdonor,X,O,Ccarbonyl], four distinct mapped
source occurrences, donor and acceptor in different source components, one common
immutable coordinate/chemical state. X is individually Cl, Br or I, neutral,
nonaromatic, singly bonded to the selected neutral carbon, with exactly that one
incident covalent edge. Cdonor source aromaticity must be known, and is retained as
AROMATIC_C or NONAROMATIC_C; this does not infer hybridization or acidity. No pooled
element identity: output names X and its source carbon environment separately.
Both donor core atoms require explicit source electronic token NONE. Acceptor is
exactly the unchanged neutral literal carbonyl-O role; its selected carbonyl parent
is retained, with explicit source electronic NONE on O and Ccarbonyl. No new donor
or acceptor role is added to I02 or any existing role manifest. Existing component
supported-element restrictions remain. Full source coverage/role replay and one
unambiguous lossless mapping required for eligibility. Nonordinary connections or
unresolved source topology cannot be silently recast as ordinary covalent input.

OPERATIONAL PREDICATE
Raw quantities: d(X,O) in angstrom; angle(Cdonor,X,O); angle(X,O,Ccarbonyl) in degrees.
Qualified candidate iff d <= 3.5 AND 130 <= donorAngle <= 180 AND
80 <= acceptorAngle <= 140. Every boundary inclusive, no epsilon or rounded test.
All three measurements must be finite, evaluated and use the same qualified frame.
Coincident/zero-vector geometry remains UNKNOWN. No H is placed or inferred.
This is an explicitly restricted ProLIF-window structural candidate, not ProLIF
parity, halogen-bond energy, an orbital claim, strength or biological relevance.
The shared source window is preserved separately for all three elements; no
invented element-specific adjustment or radius normalization.

SOURCE COMPARISON / CHOICE
Pinned ProLIF interactions.py XBAcceptor:3.5 A, AXD130..180, XAR80..140;
DoubleAngle in base.py uses distance<= and angle_between_limits in utils.py uses
inclusive comparisons. Its queries are broader (noncarbon donors, At and broad
acceptors). Athena deliberately restricts to the already available carbon-bound
Cl/Br/I identity and neutral carbonyl role. No other ProLIF chemistry is imported.
Pinned PLIP halogen uses strict distance<4.0 and MIN_DIST<distance, strict windows
165+/-30 and120+/-30 degrees. This is a different operational definition, not
combined with ProLIF. Auffinger element-dependent vdW sums and angle preferences
are survey descriptors, not independent Athena cutoff authority. Chosen contract
is the exact executable ProLIF numeric window within the declared narrower source
chemistry; no averaging or invented physical interpretation is required.

EXCLUSIONS AND UNKNOWN
F, At, N/Si/halogen-bound X, charged/radical donor core, non-carbonyl acceptors,
charged carbonyl representation, water, pi acceptors and same-component tuples
are outside this profile. They cannot establish interaction absence. Missing or
conflicting charge/H/aromaticity/electronic/source/correspondence facts are UNKNOWN;
missing current qualification remains NOT_EVALUATED. Exact source bytes/definition
or state mismatches are rejected. No accepting a convenient alternative mapping.

COVERAGE / PROVENANCE
Only the exact selected tuple may receive ABSENT_FALSE, and only after source
role replay/complete applicable source coverage plus all three measured quantities
establish eligibility and the predicate fails. No whole-system negative or count
is provided by this tuple classifier. No-radius/minimum-distance prefilter drops
far pairs; raw measurements survive independent of the predicate. Missing eligible
inventory cannot become no interaction. The collector/evaluator pins the manifest,
source group envelopes, original source coverage, exact coordinate plan, state and
measurement bytes; evaluator recomputes geometry. Governed execution uses existing
current clock/receipt checks. No production authority or synthetic receipt is issued.

REPRESENTATION / REUSE
Reuse RuleRequest.atoms ordered tuple; existing athena:group-identities and
athena-continuous-geometry-plan/1 with exactly DISTANCE,ANGLE,ANGLE operations;
existing athena:rule-measurements continuous payload and EvidenceInterpretation
measurements map for proposition/element/environment/three quantities. No public
