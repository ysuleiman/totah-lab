MODULE AND BOUNDARY
Mnemosyne follows the existing Greek architectural naming convention. The user
confirmed its role: preserve immutable scientific observations, provenance,
reviews, assessments and historical relationships; do not determine truth.
It is not a home for detailed domain results. Athena and Prometheus gain a
compile dependency on Mnemosyne; the foundation has only JDK production code.

The final interface/dependency check found no suitable existing lower-level
observation or review interface: Athena embeds DesignState, Prometheus embeds
quantum semantics, Hermes owns I/O, Gaia structure, Aether physics and DAEDALUS
execution. Class-by-class justification is in modules/mnemosyne/README.txt.
No existing public Java signature was changed. New contracts/adapters implement
the explicitly authorized slice; no historical classes or schemas were moved.

EXACT PUBLIC CONTRACTS
ScientificReference(kind, namespace, id, version). Kind discriminates ARTIFACT,
SOURCE, SUBJECT, ENDPOINT, METHOD, CONTEXT, ACTIVITY, OBSERVATION, REVIEW,
ASSESSMENT, PROPOSITION, CRITERION, POLICY, AGENT, RECEIPT and REVIEW_CHANGE.
References are opaque and immutable; authoritative external IDs are retained.

Observation(reference, subject, endpoint, method, context, activity, provenance,
availability, Optional<Scalar> value, uncertainty, limitations).
No DesignState, graph, protein, compound, assay or QuantumEvidence is required.
Availability = PRESENT / UNAVAILABLE / FAILED_INVALID. Only PRESENT carries a
scalar, and availability never implies domain validity or review approval.
Scalar(text, unit) retains original spelling and parses with BigDecimal, rejecting
nonfinite/unparseable values. No implicit numeric normalization or unit conversion.

Provenance(source, artifact, receipt, projectionMethod, locator, derivedFrom).
Raw artifact and source/version identities are separate from run/specification.
The foundation only validates reference shape; existing domain services still
verify bytes. No duplicate hash implementation was added. Athena reuses Aether
ContentHash for stable method/context references; length-prefixed sorted inputs
avoid delimiter ambiguity. Existing Hermes source verification is still required.

Uncertainty is a sealed choice:
- Unknown(reason), never interpreted as zero;
- Interval(lower Scalar, upper Scalar, description), ordered and same-unit;
- ReportedError(quantity reference, error Scalar, description), nonnegative and
  named, e.g. a reported standard error rather than an invented confidence value.
Quantitative uncertainty must use the observed scalar's unit. Both real adapter
fixtures carry unknown uncertainty. Interval/error tests use labeled synthetic
contract examples; no statistical quantities were invented for scientific data.

Review(reference, observation, reviewer, process, policy, scope, decision,
reasons, reviewedAt, recordedAt, qualifications, limitations).
Decision = ACCEPTED / REJECTED. Two decisions can disagree over one observation.
Reviewed time and knowledge/recorded time are distinct; reasons are mandatory.
The review does not alter the observation or establish globally valid evidence.

Assessment(reference, Optional observation, Optional review, proposition,
criterion, policy, context, outcome, reasons, recordedAt).
Outcome = SUPPORTS / CONTRADICTS / UNRESOLVED / FAILED_INVALID / NOT_MEASURED.
Proposition and criterion are versioned references, not a new hypothesis language.
NOT_MEASURED prohibits observation and review references. Other outcomes require
both. EvidenceHistory validates referential linkage, scope/time and admissibility
for substantive findings. No transitivity, majority vote or automatic scientific
conclusion is implemented. Policies supplied in the acceptance tests are explicit
fixture judgments about mass windows, not newly derived biological claims.

EvidenceHistory holds immutable maps of observations, reviews, assessments and
ReviewChange records. append overloads return new immutable working sets; exact
re-import is idempotent and conflicting content under one identity fails closed.
No disk persistence, SQL, graph engine or replacement registry exists here.

ReviewChange(reference, review, Optional replacement, agent, reason, effectiveAt,
recordedAt). Empty replacement is retraction; a replacement is scoped supersession.
The previous observation/review/assessment remains addressable. admissible accepts
knownAt and effectiveAt; assessmentsAsOf reconstructs recorded interpretations.
Later-known corrections do not overwrite an earlier known view. Only one withdrawal
of a review is accepted; revise its replacement for subsequent changes.

ATHENA ADAPTER
modules/athena/.../design/reasoning/ScientificObservationAdapter:
project maps the host-verified PubChem molecular-weight receipt to Observation;
review maps an explicit existing SourceDecision into a common Review;
bind verifies exact projection, matching domain review and current admissibility,
then returns Binding(observation ref, review ref, unchanged SourceDecision).
The nested Binding keeps cross-layer traceability outside the generic observation.
It is a historical linkage, not an unforgeable or perpetually current permission.

Acceptance uses the already committed CID 6343 molecular-weight JSON and existing
qualified-local-replacement knowledge fixture. One observation retains 62.14 g/mol
and its raw checksum. Independent accepted policies produce SUPPORTS for [62,63]
and CONTRADICTS for [60,61]; a biological-evidence review rejects the computed
property as biological evidence. These are deliberately scoped fixture policies.
The observation fields/raw payload remain unchanged. Existing DesignKnowledge,
hypothesis requirements and planner consume its externally bound evidence.
A later retraction blocks a new binding; an earlier as-of binding reconstructs.
No new compounds are produced by the added adapter tests. Existing bounded
acceptance tests still exercise their pre-existing synthetic edit fixtures.

PROMETHEUS ADAPTER
modules/prometheus/.../evidence/ScientificObservationAdapter.energy projects
QuantumEvidence.energyHartree without modifying EvidenceIdentity, registry,
acceptance, lifecycle, retry, PRIMARY/AUXILIARY or reuse semantics.
The calculation-specification hash remains a method/context reference, never an
automatic run or observation ID. Existing source path/hash, receipt identity,
derivation hashes, convergence/acceptance and limitations remain traceable.
Double.toString is used because the existing domain result holds Double; the
original lexical representation, where available, remains in the raw artifact.

PySCF 2.14.0, FORCE_EVALUATION with energy/gradient/forces outputs. It is
materialized only in JUnit temporary storage, exactly as the existing test does.
No quantum calculation is run. ArtifactChecksums verifies actual raw bytes.
Tests show the projection does not change registry bytes or PRIMARY/AUXILIARY
reuse eligibility. Legacy declared non-SHA placeholders can remain opaque
references under a distinct namespace; the adapter never calls them verified SHA.

IDENTITY / REPLICATES / COMPATIBILITY
Equal values, byte hashes or specification hashes do not collapse independently
identified runs and observations. Tests explicitly preserve two observations with
the same value/specification and separate run IDs; exact re-import is idempotent;
changed value or run under the same observation identity conflicts. Caller-supplied
run identities are not proof that independent physical experiments occurred.

Existing SourceReceipt, SourceReview, DesignKnowledge schemas 1/2, journal payloads,
registry formats and Prometheus evidence remain unchanged. Adapter-first only.
Legacy planning, source-review, structural association and journal/snapshot
acceptance tests were rerun. Source and interpretation authorities remain in their
original modules. No frozen artifacts, scientific conclusions or backend IDs changed.

KNOWN LIMITATIONS AND NEXT REVIEW
- EvidenceHistory is bounded and in memory. No durable cross-domain schema/store,
  restart recovery, authentication, signature or multi-writer guarantee is claimed.
- Referenced source/protocol/context definitions resolve through existing domain
  receipts/hosts; no universal catalog or reference resolver is introduced.
- Assessments are attributed policy assertions, not automatic scientific evaluation.
  Rejected/missing references and invalid linkage are checked, not truth of reasons.
- Scalar-only values; error/interval descriptions preserve source meaning without
  a complete statistics model. No automatic units or endpoint comparability.
- Source import integrity remains Hermes' responsibility. The new Athena projector
  cannot substitute for readVerified; binding reuses existing domain qualification.
- Existing accepted snapshots remain historical: retractions do not mutate them.
  New bindings must use the current appropriate history. Existing consumers are
  not silently switched to a global continuously updated admissibility service.
- Review supersession is deliberately limited to the same reviewer/observation/scope;
  no broad hypothesis language, generalized revision DAG or inference engine.
- Detailed quantum data, acceptance/training roles and reuse remain Prometheus-owned.

Recommended next slice, only after review: a small versioned exchange/round-trip
contract for these immutable records plus verified reference resolution to the
existing domain receipts. Characterize exact-byte/semantic round trips and
historical as-of reconstruction before selecting persistence. Do not add a
universal database or expand observation payloads merely for completeness.
