# Validation architecture

Validation is preregistered and blinded. Dataset splitting rejects overlap. Development strategies receive development evidence only. Holdout values become accessible only after a candidate is immutable, checksummed, and paired with a validation plan. Holdout failure cannot trigger automatic refitting.

Evidence acceptance verifies checksum, mapping, convergence, protocol, electronic state, requested outputs, and geometry. Interaction probes also require clash auditing. Geometry-invalid probes remain archived but cannot enter validation statistics.

Metrics remain separate by scientific dimension. Prometheus never produces a master score. Candidate decisions require every declared gate and carry explicit reasons. Improvement over a baseline alone is not production validation.
