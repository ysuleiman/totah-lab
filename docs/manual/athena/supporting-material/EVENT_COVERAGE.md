# Explicit event coverage, counts and topology

The approved operational contract is the authority for these descriptive semantics.
[Payload contracts](../../../../software/qualification/event-coverage-20261006/PAYLOAD_CONTRACTS.txt)
record the exact fields, canonical identity, source binding, assessment/negative coverage,
eligible denominator, correspondence and traversal semantics. The
[approval](../../../../software/qualification/event-coverage-20261006/APPROVAL.txt)
is attributed user authorization, not a fabricated research-review signature or receipt.

The accepted inventory entries N02/N03/N04/G08/I20 and existing
[source map](../../../../software/qualification/scientific-rule-knowledge-audit-20261004/SOURCE_MAP.json)
pin the earlier methodological research. ProLIF commit
`19f1800218387c49536eb9d3e8cd3044fdb337ee`, `prolif/fingerprint.py` (Fingerprint,
generate, to_dataframe/to_bitvectors) supplies a precedent for selected-state
fingerprints and atom-attributed interaction records. It does not establish that
unrecorded observations are scientifically false. RING's pinned usage/results material
supplies a typed-network precedent; the inventory preserves the limitations of
available executable-source inspection. Neither supplies a causal/energetic network
interpretation. This milestone reuses those sources without new literature research.

**ADOPT:** explicit event identity, partner attribution and descriptive selected-state
aggregation; typed paths assembled from qualified evidence.
**MODIFY:** Athena requires independent complete-scope coverage for negatives, preserves
six source assessment states and conflicts, and exposes exact eligible denominators.
**REJECT:** absent fingerprint entries as negatives; duplicate-record multiplicity;
implicit ensemble selection; pairing unrelated ensembles; probability, causal correlation,
energy transfer or mechanism inferred from counts/paths.
**UNSUPPORTED:** deriving chemical interaction truth from legacy positive-only fingerprints;
water/metal/sulfur chemistry not supplied by qualified upstream rules; automatic production
qualification. No empirical dataset or fitted threshold is needed for these exact finite
counts and graph-topology propositions. Upstream scientific sources remain responsible
for their own chemical/geometric domains.

Synthetic fixtures challenge missing/false, all six statuses, conflicting assertions,
symmetry/correspondence alternatives, duplicate occurrences, zero denominators, asymmetric
common-state eligibility, cyclic/directed/undirected/bounded paths, unqualified edges,
coverage and hash tampering, explicit versus inherited evidence, persistence and current
receipt verification. These are engineering witnesses, not molecular observations.
The historical-fingerprint implementation and scientific outputs remain unchanged.

Implementation owners: Athena package-private EventAnalysisRules, EventInputs, EventCounts,
EventPaths, EventPayload and EventSourceQualification; Daedalus EventAssessmentInputs routes
only explicit plan selections through existing CurrentRuleExecution. Existing Mnemosyne
EvidenceExchange/catalog preserves inputs and newly attributed Findings. No new graph engine,
database, matcher or public Java API. Manifest `athena.events/1` is an inactive /2 template;
real current-policy execution requires /3 eligibility, implementation receipt and execution
binding. It has not been activated by the engineering tests.
