This is orchestration provenance, not a new scientific definition or biological claim.
The reviewed contract is [the immutable prospective design](../../../../software/qualification/direct-assessment-execution-contract-20261005/DESIGN.txt),

preserves the original integration witness and its harness correction.

## Why this entry point exists

`SystemQualificationPipeline` already stores direct Findings. Historical
`RuleExecutionPipeline.run` and current-policy `runCurrent` compose a measurement
collector and evaluator. A source-connectivity proposition need not manufacture a
measurement payload in order to enter research/implementation qualification.
`evaluateCurrent` reuses `CurrentRuleExecution` admission, definition binding,
research eligibility, implementation qualification, receipt re-verification and time
authority. It skips only the measurement-producing stage. It returns existing `Published`.

ADOPT: evidence-first persistence and explicit snapshot/input selection; reuse existing
gates, generic Findings, receipts and catalogs. REJECT: implicit selection of inherited
coverage, fake measurement schemas, eligibility as qualification, automatic capability
promotion, or migration of historical rule receipts. DEFER: other direct predicates.

## Selection and provenance

`ResearchExecutionInputs.artifacts` selects this execution's evidence. Everything supplied
is admitted before interpretation. Being admitted does not make an artifact a scientific
input. The initial adapter accepts only explicitly supplied `athena:group-source-coverage`
with `/1` schema, matching state binding, and a component correspondence relevant to the
selected sulfur pair. Wrong state/schema/component/hash fails closed. Coverage of another
component remains stored but is excluded. Opaque research/other artifacts remain stored;
they are not passed as source coverage. Missing selected coverage is permitted and yields
an inconclusive missing-edge assessment, never borrowed historical completeness.

The adapter verifies routing/binding; the existing B06 implementation remains the authority
for topology, mapping and coverage semantics. Selected input references/hashes are recorded
in an administrative selection Finding. Immediately before evaluator invocation, time and
receipt are rechecked and the selected applicable set is resolved again. Final Findings
are persisted against the applicable set and authoritative system-state envelope. Conflicts
are neither overwritten nor resolved by recency. A positive Finding cannot grant a new
system capability; the guarded analyzer advertises no qualifying capabilities.

## Bounded implementation and limits

Only the corrected `athena.ss-connectivity/1` supports this direct entry point initially.
An explicitly constructed `/3` binding is required; shipped `/2` remains candidate-gated.
Its [scientific source-connectivity definition](SS_CONNECTIVITY_COVERAGE.md) is unchanged.
No disulfide, redox, geometry or favorable-contact inference is added. `runCurrent` rejects
this new direct `/3` binding before collection. Historical `/1`, `/2`, `run` and existing
measurement-producing `/3` behavior remain independently replayed.

The acceptance dossiers, reviewers, expiry dates and receipts are synthetic engineering
fixtures only. They establish gate correctness, not actual scientific review or activation.
No production current-policy scientific receipt is issued by this checkpoint.
